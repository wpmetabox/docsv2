## What is Meta Box?

When you use WordPress as a CMS (not just for blogging), you need more than just posts and pages. For example, to show events on your website, you need a content type called "event" with some fields to store event details such as date and location. In WordPress, we call them [custom post type](/custom-post-types/) and [custom field](/custom-fields/). To create custom post types and custom fields, you need a plugin like Meta Box.

Meta Box is a framework that helps you create custom post types and custom fields quickly and easily. A framework provides all the tools you need to manage data and build features for your WordPress websites. It saves you time and lets you focus on business logic.

Meta Box provides powerful features [via extensions](/extensions/). These include front-end form submission, post relationships, custom table storage, conditional logic, Gutenberg blocks, and integrations with many third-party plugins.

Whether you are a WordPress user or developer, Meta Box is a toolkit that grows with you. We help you boost your productivity and workflow. We cannot wait to see what you build.

## Why Meta Box?

There are many plugins for working with custom fields. We believe Meta Box is the best choice for building a performant and full-featured website.

**Easy for everyone**

With a user-friendly interface, low-code features, and built-in snippets, you can work with Meta Box easily even if you are not a developer.

**Full-featured**

Meta Box offers the most complete set of features among custom fields plugins. Whatever you need, Meta Box has it for you.

**Lightweight & fast**

Being thoroughly optimized for code and data storage, Meta Box never impacts your website speed or performance.

**Extensibility**

With APIs and actions, filters in many necessary places, you can change how to display fields, change data, or do other things like sending emails.

Learn more about [Meta Box philosophy](/philosophy/).

## Meta Box overview

Meta Box has 3 versions:

* **Meta Box**: the foundation and framework of all [extensions](https://docs.metabox.io/extensions/) and features. You can add individual extensions (free or premium) to have advanced features. It has no UI and suits developers only, who need to use code.
* [**Meta Box Lite**](https://metabox.io/lite/): a single free UI version of Meta Box. It includes the Meta Box plugin, [MB Builder](/extensions/meta-box-builder/), and all the free extensions to create custom post types, custom taxonomies, custom fields, and relationships.
* [**Meta Box AIO**](https://metabox.io/aio/): a single premium plugin. It includes the Meta Box plugin and all the extensions (both free and premium). Meta Box AIO lets you install only one plugin and have everything from Meta Box, so the plugin list stays short and clean.

In short, if you are a free user, use Meta Box Lite. For paid users, use Meta Box AIO!
