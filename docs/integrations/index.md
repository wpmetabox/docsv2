Meta Box works with most WordPress plugins and themes. We test Meta Box with many popular plugins and themes. These include page builders, form plugins, search and filter plugins, SEO plugins, and multilingual plugins.

## Plugins

Meta Box works with other plugins in two ways:

- **Official support**: The plugin has built-in support for Meta Box. You do not need extra setup.
- **MB extension**: A Meta Box extension connects Meta Box to the plugin. Install the extension to use the integration.

### Page builder plugins

Display custom fields in your pages with page builders.

- Beaver Builder - use the [MB Beaver Builder Integration](https://metabox.io/plugins/meta-box-beaver-themer-integrator/)
- Elementor - use the [MB Elementor Integration](https://metabox.io/plugins/mb-elementor-integrator/)
- Oxygen Builder - official support from Oxygen Builder since version 3.9 Beta 1
- Brizy - official support from Brizy
- Bricks - official support from Bricks

### Form plugins

Use these plugins to collect and connect form fields to Meta Box fields. These plugins have official support for Meta Box:

- Fluent Forms
- WS Form
- Bit Form
- Piotnet Forms

### Search and filter plugins

Let visitors search and filter content by Meta Box fields.

- FacetWP - use the [MB FacetWP Integration](https://metabox.io/plugins/meta-box-facetwp-integrator/)
- FilterWP - official support from FilterWP
- SearchWP - use the [MB SearchWP Integration](https://metabox.io/plugins/meta-box-searchwp-integrator/)
- GridbuilderWP - official support from GridbuilderWP
- Piotnet Grid Builder - official support from Piotnet Grid Builder
- [Queryra](https://queryra.com/) - AI search platform, use [their official integration](https://queryra.com/docs/meta-box-integration)

### SEO plugins

Make your custom fields visible to search engines.

- [Slim SEO](https://wpslimseo.com/)
- Rank Math - use the [MB Rank Math](https://metabox.io/plugins/mb-rank-math/) extension
- Yoast SEO - use the [MB Yoast SEO Integration](https://metabox.io/plugins/meta-box-yoast-seo/) extension

### Multilingual plugins

Meta Box has built-in integration for these multilingual plugins. Use them to translate values in custom fields.

- [WPML](/integrations/wpml/)
- [Polylang](/integrations/polylang/)

### Other plugins

- [Auto Listings](https://wpautolistings.com/)
- [WordPress Ultimate CSV, XML Importer Pro](https://www.smackcoders.com/wp-ultimate-csv-importer-pro.html/)
